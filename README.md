# Модель Шеллинга с ассимиляцией — вычислительный пакет

Исследование моделей сегрегации Томаса Шеллинга и их расширений. 

## Структура проекта

```
schelling_project/
├── core/                    # ядро: модель и движки
│   ├── topologies.py        #   геометрии: кольцо (1D), тор (2D, Мур/фон Нейман)
│   ├── policies.py          #   поведение: ThresholdSatisfaction, RandomVacancyMove, FlipOrMove
│   ├── simulation.py        #   базовый движок (эталон, полный пересчёт counts)
│   ├── fast.py              #   FastSimulation: инкрементальные counts, O(m·z) на шаг
│   ├── kmc.py               #   KMCSimulation: события Гиллеспи (kinetic Monte Carlo)
│   ├── observables.py       #   метрики: isolation, duncan, structure_factor, cluster_stats, …
│   └── factories.py         #   сборка моделей make_schelling_1d / make_schelling_2d
├── experiments/             # численные эксперименты (офлайн)
│   ├── common.py            #   общие помощники (сборка, протокол измерения I)
│   ├── phase_diagram.py     #   фазовая диаграмма I(T, p), параллельно по сидам
│   ├── hysteresis.py        #   скан T вверх/вниз — проверка метастабильности
│   ├── growth.py            #   кинетика укрупнения доменов R(t) ~ t^α
│   └── benchmark.py         #   сравнение трёх движков по скорости
├── tests/
│   └── test_engines.py      # тесты: битовая идентичность движков, инварианты KMC
├── vizual/
│   └── animate.py           # интерактивная анимация (Taichi GUI + ползунки + спарклайны)
├── figures/                 # сгенерированные графики
├── results/                 # сырые данные экспериментов (.npz)
├── ОТЧЁТ.md                 # полный отчёт: теория, расчёты, результаты, литература
└── README.md                # этот файл
```

## Установка

```bash
python -m venv .venv          # Python 3.10+ (для vizual нужен taichi: ≤3.12)
.venv/Scripts/activate        # Windows; на Linux: source .venv/bin/activate
pip install numpy scipy matplotlib pillow taichi pytest
```

Минимум для ядра и экспериментов: `numpy`, `scipy`, `matplotlib`.
`taichi` и `pillow` нужны только для интерактивной анимации.

## Быстрый старт

### Интерактивная анимация

```bash
python -m vizual.animate --dim 2                 # тор 160×160
python -m vizual.animate --dim 1 --length 400    # кольцо + пространственно-временная диаграмма
```

Управление: ползунки T / p / ρ мышью; `SPACE` — пауза; `R` — перезапуск;
`←/→` — порог T; `↑/↓` — вероятность флипа p; `[`/`]` — скорость;
`U` — подсветка несчастных агентов (2D); `ESC` — выход.
Справа на панели — истории I(t) и happy(t) (искровые графики).

### Эксперименты

```bash
python -m experiments.phase_diagram --size 64 --seeds 4   # карта I(T, p)
python -m experiments.hysteresis --size 64                # петля гистерезиса I(T)
python -m experiments.growth --size 128 --steps 400       # рост доменов R(t)
python -m experiments.benchmark --size 200 --steps 40     # движки: скорость
```

Результаты: `figures/*.png` + `results/*.npz`.

### Тесты

```bash
python tests/test_engines.py     # или: python -m pytest tests/ -q
```

## Три движка: когда какой

| Движок | Стоимость MCS | Когда использовать |
|---|---|---|
| `Simulation` (базовый) | O(z·K·N) полных проходов | эталон, отладка, малые системы |
| `FastSimulation` | O(m·z), m — число действий | основной рабочий; выигрыш растёт с z·K и в замороженной фазе |
| `KMCSimulation` | O(z) на событие | непрерывное время, строгое соответствие мастер-уравнению ẋ = Qx; огромный выигрыш в замороженной фазе (p = 0) |

Ключевые гарантии (проверяются тестами):

- при одинаковом seed траектории `Simulation` и `FastSimulation`
  **совпадают бит-в-бит** (одинаковый порядок обращений к ГСЧ);
- стационарный индекс изоляции KMC и батч-MCS согласуется в пределах
  статистической ошибки (см. отчёт, раздел 4.4): время KMC измеряется
  в MCS-эквивалентах (1 MCS = среднее время одного действия на агента).

## Метрики (`core/observables.py`)

| Имя | Что измеряет |
|---|---|
| `isolation` | доля «своих» среди занятых соседей; ~0.5 — смешение, 1 — полная сегрегация |
| `duncan` | индекс диссимилярности Данкана по окрестностям (K = 2) |
| `structure_factor` | S(q) — радиально усреднённый спектр поля типов; пик q* ↔ размер домена |
| `cluster_stats` | число и размеры доменов (связные компоненты одного типа) |
| `type_fractions` | доли типов среди занятых клеток |

Доступ из симуляции: `sim.observe("isolation")`, `sim.observe("cluster_stats")` и т.д.

## Модель (кратко)

Агенты K типов на кольце/торе с плотностью занятости ρ. Агент счастлив,
если доля «своих» среди **занятых** соседей ≥ T. За шаг агент выбирает
одно действие: с вероятностью p — флип (смена типа на случайный другой,
«ассимиляция»), иначе, если несчастен, — переезд в случайную свободную
клетку. Решения принимаются по состоянию на начало шага.
